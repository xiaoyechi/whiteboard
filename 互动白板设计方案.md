## 1. 数据同步策略

### 1.1 多层级同步架构

#### 层级 1：操作级同步（实时性）
**目的**：保证用户操作的实时反馈

**实现方式**：
- 使用 WebSocket 进行双向实时通信
- 每个操作立即发送到服务器并广播给其他客户端
- 操作粒度：单个笔触的开始、点添加、结束

**数据结构**：
```typescript
interface Operation {
  id: string;                    // 操作唯一ID
  type: 'stroke_start' | 'stroke_point' | 'stroke_end' | 
        'erase' | 'move' | 'delete' | 'select';
  userId: string;                // 用户ID
  timestamp: number;              // 客户端时间戳
  serverTimestamp?: number;       // 服务器时间戳（用于排序）
  data: OperationData;           // 操作数据
  version: number;                // 版本号（用于冲突检测）
}

interface StrokeOperationData {
  strokeId: string;
  point?: Point;
  stroke?: Stroke;
  // ... 其他操作特定数据
}
```

**优势**：
- 延迟低（通常 < 100ms）
- 用户体验好，实时看到他人操作
- 适合高频操作（如绘制）

**劣势**：
- 网络不稳定时可能丢失操作
- 需要处理操作顺序问题

#### 层级 2：批量同步（效率）
**目的**：减少网络开销，提高效率

**实现方式**：
- 收集一段时间内的操作（如 100ms）
- 批量发送和接收
- 使用操作压缩（如只发送关键点）

**适用场景**：
- 快速绘制时
- 网络带宽有限时
- 移动端场景

#### 层级 3：快照同步（一致性）
**目的**：保证数据一致性，处理断线重连

**实现方式**：
- 定期生成完整画布快照（如每 10 秒）
- 使用版本号标记快照
- 断线重连时拉取最新快照 + 增量操作

**数据结构**：
```typescript
interface Snapshot {
  version: number;                // 快照版本号
  timestamp: number;               // 生成时间
  canvasState: CanvasState;       // 完整画布状态
  checksum: string;                // 校验和（用于验证完整性）
}
```

**优势**：
- 保证数据一致性
- 支持断线重连
- 可以作为备份

### 1.2 操作排序与合并

#### 问题：操作顺序不一致
不同客户端可能以不同顺序收到操作，导致最终状态不一致。

#### 解决方案：向量时钟（Vector Clock）

```typescript
interface VectorClock {
  [userId: string]: number;       // 每个用户的操作计数
}

interface Operation {
  // ... 其他字段
  vectorClock: VectorClock;       // 向量时钟
}
```

**工作原理**：
1. 每个用户维护自己的向量时钟
2. 发送操作时，递增自己的计数器
3. 接收操作时，合并向量时钟
4. 使用向量时钟比较操作顺序

**示例**：
```
用户A: [A:2, B:1, C:0]
用户B: [A:1, B:2, C:0]
用户C: [A:1, B:1, C:1]

操作顺序：按向量时钟比较，确定全局顺序
```

### 1.3 操作压缩与优化

#### 点压缩算法
绘制时会产生大量点，需要压缩：

```typescript
// 道格拉斯-普克算法（Douglas-Peucker）
function simplifyPoints(points: Point[], tolerance: number): Point[] {
  if (points.length <= 2) return points;
  
  // 找到距离首尾连线最远的点
  let maxDistance = 0;
  let maxIndex = 0;
  
  for (let i = 1; i < points.length - 1; i++) {
    const distance = pointToLineDistance(
      points[i], 
      points[0], 
      points[points.length - 1]
    );
    if (distance > maxDistance) {
      maxDistance = distance;
      maxIndex = i;
    }
  }
  
  // 如果最远距离大于阈值，递归处理
  if (maxDistance > tolerance) {
    const left = simplifyPoints(points.slice(0, maxIndex + 1), tolerance);
    const right = simplifyPoints(points.slice(maxIndex), tolerance);
    return [...left.slice(0, -1), ...right];
  }
  
  return [points[0], points[points.length - 1]];
}
```

  - 定期保存到本地（如每 5 秒）

## 3. 纠错与冲突解决

### 3.1 冲突类型与详细解决方案

#### 场景 1：同时修改同一笔触

**问题描述**：
- 用户A和用户B同时编辑同一个笔触（如移动、修改颜色、删除等）
- 两个操作可能同时到达服务器，导致状态不一致

**解决方案 1：乐观锁机制（推荐）**

使用版本号（Version）或时间戳（Timestamp）实现乐观锁：

```typescript
interface Stroke {
  id: string;
  // ... 其他字段
  version: number;              // 版本号（每次修改递增）
  lastModifiedBy: string;       // 最后修改者
  lastModifiedAt: number;      // 最后修改时间戳
}

// 修改笔触时检查版本号
function updateStroke(
  strokeId: string,
  updates: Partial<Stroke>,
  expectedVersion: number
): OperationResult {
  const currentStroke = getStroke(strokeId);
  
  // 检查版本号是否匹配
  if (currentStroke.version !== expectedVersion) {
    return {
      success: false,
      error: 'CONFLICT',
      message: '笔触已被其他用户修改，请刷新后重试',
      currentVersion: currentStroke.version,
      currentStroke: currentStroke,
    };
  }
  
  // 版本号匹配，执行更新
  const updatedStroke = {
    ...currentStroke,
    ...updates,
    version: currentStroke.version + 1,
    lastModifiedBy: getCurrentUserId(),
    lastModifiedAt: Date.now(),
  };
  
  saveStroke(updatedStroke);
  return { success: true, stroke: updatedStroke };
}
```

**客户端处理冲突**：
```typescript
async function handleUpdateStroke(strokeId: string, updates: Partial<Stroke>) {
  const localStroke = getLocalStroke(strokeId);
  const expectedVersion = localStroke.version;
  
  try {
    const result = await updateStroke(strokeId, updates, expectedVersion);
    
    if (!result.success && result.error === 'CONFLICT') {
      // 冲突处理：显示提示，让用户选择
      showConflictDialog({
        localVersion: localStroke,
        serverVersion: result.currentStroke,
        onResolve: (choice) => {
          if (choice === 'keep_local') {
            // 保留本地版本（需要重新提交）
            retryUpdateWithNewVersion(result.currentStroke, updates);
          } else if (choice === 'use_server') {
            // 使用服务器版本
            updateLocalState(result.currentStroke);
          } else if (choice === 'merge') {
            // 尝试合并（智能合并）
            const merged = mergeStrokeChanges(
              result.currentStroke,
              updates
            );
            retryUpdateWithNewVersion(result.currentStroke, merged);
          }
        },
      });
    }
  } catch (error) {
    handleError(error);
  }
}
```

**解决方案 2：操作转换（OT - Operational Transformation）**

对于可以合并的操作，使用操作转换：

```typescript
// 移动操作的转换
function transformMoveMove(
  op1: MoveOperation,
  op2: MoveOperation
): [MoveOperation, MoveOperation] {
  if (op1.strokeId !== op2.strokeId) {
    // 不同笔触，无需转换
    return [op1, op2];
  }
  
  // 同一笔触的移动：合并移动距离
  return [
    op1,
    {
      ...op2,
      dx: op2.dx,  // 第二个操作保持原样
      dy: op2.dy,
      // 但需要知道第一个操作的影响
      baseVersion: op1.version + 1,
    },
  ];
}

// 修改颜色操作的转换
function transformColorColor(
  op1: ColorChangeOperation,
  op2: ColorChangeOperation
): [ColorChangeOperation, ColorChangeOperation] {
  if (op1.strokeId !== op2.strokeId) {
    return [op1, op2];
  }
  
  // 后执行的覆盖先执行的
  if (op1.timestamp < op2.timestamp) {
    return [op1, op2]; // op2 覆盖 op1
  } else {
    return [op1, { ...op2, type: 'noop' }]; // op1 覆盖 op2
  }
}
```

**解决方案 3：最后写入获胜（LWW - Last Write Wins）**

简单场景下的快速解决方案：

```typescript
function resolveStrokeConflict(
  strokeA: Stroke, 
  strokeB: Stroke
): Stroke {
  // 优先使用服务器时间戳（更可靠）
  if (strokeA.serverTimestamp && strokeB.serverTimestamp) {
    return strokeA.serverTimestamp > strokeB.serverTimestamp 
      ? strokeA 
      : strokeB;
  }
  
  // 回退到客户端时间戳
  if (strokeA.timestamp > strokeB.timestamp) {
    return strokeA;
  } else if (strokeB.timestamp > strokeA.timestamp) {
    return strokeB;
  }
  
  // 时间戳相同，使用用户ID作为tie-breaker
  return strokeA.userId > strokeB.userId ? strokeA : strokeB;
}
```

**解决方案 4：操作队列与顺序执行**

服务器端维护操作队列，按顺序执行：

```typescript
class OperationQueue {
  private queue: Operation[] = [];
  private processing = false;
  
  async enqueue(operation: Operation): Promise<void> {
    // 分配全局顺序号
    operation.sequenceNumber = await this.getNextSequenceNumber();
    this.queue.push(operation);
    
    if (!this.processing) {
      this.processQueue();
    }
  }
  
  private async processQueue(): Promise<void> {
    this.processing = true;
    
    while (this.queue.length > 0) {
      const operation = this.queue.shift()!;
      
      try {
        await this.executeOperation(operation);
        await this.broadcastOperation(operation);
      } catch (error) {
        // 处理失败的操作
        this.handleOperationError(operation, error);
      }
    }
    
    this.processing = false;
  }
}
```

#### 场景 2：不同用户笔触数据不一致

**问题描述**：
- 用户A看到的画布状态与用户B不同
- 可能原因：网络延迟、操作丢失、断线重连、并发冲突

**解决方案 1：状态同步与校验**

**定期状态校验**：
```typescript
class StateSynchronizer {
  private lastSyncTime = 0;
  private syncInterval = 5000; // 5秒同步一次
  
  async syncState(): Promise<void> {
    const localState = getLocalState();
    const localChecksum = calculateChecksum(localState);
    
    // 请求服务器状态
    const serverState = await fetchServerState();
    const serverChecksum = calculateChecksum(serverState);
    
    if (localChecksum !== serverChecksum) {
      // 状态不一致，需要修复
      await this.resolveStateInconsistency(localState, serverState);
    }
    
    this.lastSyncTime = Date.now();
  }
  
  private async resolveStateInconsistency(
    localState: CanvasState,
    serverState: CanvasState
  ): Promise<void> {
    // 1. 找出不一致的笔触
    const inconsistencies = this.findInconsistencies(
      localState,
      serverState
    );
    
    if (inconsistencies.length === 0) {
      return; // 实际上是一致的（可能是校验和计算问题）
    }
    
    // 2. 根据不一致类型选择修复策略
    for (const inconsistency of inconsistencies) {
      await this.resolveInconsistency(inconsistency);
    }
  }
  
  private findInconsistencies(
    local: CanvasState,
    server: CanvasState
  ): Inconsistency[] {
    const inconsistencies: Inconsistency[] = [];
    const localStrokes = new Map(local.strokes.map(s => [s.id, s]));
    const serverStrokes = new Map(server.strokes.map(s => [s.id, s]));
    
    // 检查本地有但服务器没有的笔触
    for (const [id, stroke] of localStrokes) {
      if (!serverStrokes.has(id)) {
        inconsistencies.push({
          type: 'local_only',
          strokeId: id,
          localStroke: stroke,
        });
      }
    }
    
    // 检查服务器有但本地没有的笔触
    for (const [id, stroke] of serverStrokes) {
      if (!localStrokes.has(id)) {
        inconsistencies.push({
          type: 'server_only',
          strokeId: id,
          serverStroke: stroke,
        });
      }
    }
    
    // 检查版本不一致的笔触
    for (const [id, localStroke] of localStrokes) {
      const serverStroke = serverStrokes.get(id);
      if (serverStroke && localStroke.version !== serverStroke.version) {
        inconsistencies.push({
          type: 'version_mismatch',
          strokeId: id,
          localStroke,
          serverStroke,
        });
      }
    }
    
    return inconsistencies;
  }
  
  private async resolveInconsistency(
    inconsistency: Inconsistency
  ): Promise<void> {
    switch (inconsistency.type) {
      case 'local_only':
        // 本地有但服务器没有：可能是未同步的操作
        await this.syncLocalStrokeToServer(inconsistency.localStroke!);
        break;
        
      case 'server_only':
        // 服务器有但本地没有：添加服务器笔触
        addStrokeToLocal(inconsistency.serverStroke!);
        break;
        
      case 'version_mismatch':
        // 版本不一致：使用较新的版本
        const resolved = resolveVersionConflict(
          inconsistency.localStroke!,
          inconsistency.serverStroke!
        );
        updateLocalStroke(resolved);
        break;
    }
  }
}
```

**解决方案 2：向量时钟（Vector Clock）**

使用向量时钟追踪操作的因果关系：

```typescript
interface VectorClock {
  [userId: string]: number;  // 每个用户的操作计数
}

interface Stroke {
  id: string;
  // ... 其他字段
  vectorClock: VectorClock;  // 向量时钟
}

// 比较两个笔触的因果关系
function compareVectorClocks(
  vc1: VectorClock,
  vc2: VectorClock
): 'before' | 'after' | 'concurrent' {
  let vc1Before = false;
  let vc2Before = false;
  
  const allUsers = new Set([
    ...Object.keys(vc1),
    ...Object.keys(vc2),
  ]);
  
  for (const user of allUsers) {
    const count1 = vc1[user] || 0;
    const count2 = vc2[user] || 0;
    
    if (count1 < count2) vc2Before = true;
    if (count2 < count1) vc1Before = true;
  }
  
  if (vc1Before && !vc2Before) return 'before';
  if (vc2Before && !vc1Before) return 'after';
  return 'concurrent'; // 并发操作
}

// 合并向量时钟
function mergeVectorClocks(
  vc1: VectorClock,
  vc2: VectorClock
): VectorClock {
  const merged: VectorClock = {};
  const allUsers = new Set([
    ...Object.keys(vc1),
    ...Object.keys(vc2),
  ]);
  
  for (const user of allUsers) {
    merged[user] = Math.max(vc1[user] || 0, vc2[user] || 0);
  }
  
  return merged;
}

// 解决并发冲突
function resolveConcurrentConflict(
  stroke1: Stroke,
  stroke2: Stroke
): Stroke {
  const relation = compareVectorClocks(
    stroke1.vectorClock,
    stroke2.vectorClock
  );
  
  if (relation === 'before') return stroke2;
  if (relation === 'after') return stroke1;
  
  // 并发冲突：使用时间戳或用户优先级
  if (stroke1.timestamp > stroke2.timestamp) {
    return stroke1;
  } else if (stroke2.timestamp > stroke1.timestamp) {
    return stroke2;
  }
  
  // 时间戳也相同，使用用户ID
  return stroke1.userId > stroke2.userId ? stroke1 : stroke2;
}
```

**解决方案 3：操作日志重放**

通过重放操作日志恢复一致状态：

```typescript
class OperationReplay {
  async replayToConsistency(
    baseState: CanvasState,
    operations: Operation[]
  ): Promise<CanvasState> {
    let state = { ...baseState };
    
    // 按顺序重放操作
    for (const operation of operations) {
      // 检查操作是否已应用（幂等性）
      if (state.appliedOperations?.has(operation.id)) {
        continue;
      }
      
      // 应用操作
      state = this.applyOperation(state, operation);
      
      // 记录已应用的操作
      if (!state.appliedOperations) {
        state.appliedOperations = new Set();
      }
      state.appliedOperations.add(operation.id);
    }
    
    return state;
  }
  
  private applyOperation(
    state: CanvasState,
    operation: Operation
  ): CanvasState {
    switch (operation.type) {
      case 'stroke_add':
        return {
          ...state,
          strokes: [...state.strokes, operation.data.stroke],
        };
        
      case 'stroke_update':
        return {
          ...state,
          strokes: state.strokes.map(s =>
            s.id === operation.data.strokeId
              ? { ...s, ...operation.data.updates }
              : s
          ),
        };
        
      case 'stroke_delete':
        return {
          ...state,
          strokes: state.strokes.filter(
            s => s.id !== operation.data.strokeId
          ),
        };
        
      default:
        return state;
    }
  }
}
```

**解决方案 4：快照 + 增量同步**

定期使用快照确保一致性：

```typescript
class SnapshotSync {
  private snapshotInterval = 10000; // 10秒
  
  async ensureConsistency(): Promise<void> {
    // 1. 获取服务器最新快照
    const serverSnapshot = await this.fetchLatestSnapshot();
    
    // 2. 获取本地状态
    const localState = getLocalState();
    
    // 3. 比较版本号
    if (localState.version < serverSnapshot.version) {
      // 本地落后，需要同步
      await this.syncFromSnapshot(serverSnapshot);
    } else if (localState.version > serverSnapshot.version) {
      // 本地超前，可能有未同步的操作
      await this.syncToServer(localState);
    } else {
      // 版本相同，但可能内容不一致（校验和验证）
      const localChecksum = calculateChecksum(localState);
      if (localChecksum !== serverSnapshot.checksum) {
        // 内容不一致，使用服务器快照
        await this.syncFromSnapshot(serverSnapshot);
      }
    }
  }
  
  private async syncFromSnapshot(snapshot: Snapshot): Promise<void> {
    // 1. 保存本地未同步操作
    const pendingOps = this.getPendingOperations();
    
    // 2. 应用快照
    updateLocalState(snapshot.canvasState);
    
    // 3. 重放未同步操作（需要转换）
    for (const op of pendingOps) {
      const transformedOp = await this.transformOperation(
        op,
        snapshot.canvasState
      );
      applyOperation(transformedOp);
    }
  }
}
```

**解决方案 5：冲突检测与用户提示**

当检测到不一致时，提示用户并让用户选择：

```typescript
class ConflictResolver {
  async detectAndResolve(): Promise<void> {
    const conflicts = await this.detectConflicts();
    
    if (conflicts.length === 0) {
      return; // 无冲突
    }
    
    // 显示冲突提示
    const userChoice = await this.showConflictDialog(conflicts);
    
    switch (userChoice.strategy) {
      case 'auto_resolve':
        // 自动解决（使用服务器版本）
        await this.autoResolve(conflicts);
        break;
        
      case 'manual_merge':
        // 手动合并
        await this.manualMerge(conflicts, userChoice.choices);
        break;
        
      case 'keep_local':
        // 保留本地版本（强制同步到服务器）
        await this.forceSyncLocal(conflicts);
        break;
        
      case 'use_server':
        // 使用服务器版本
        await this.useServerVersion(conflicts);
        break;
    }
  }
}

#### 类型 2：操作顺序冲突
**场景**：不同客户端以不同顺序收到操作

**解决方案：操作转换（Operational Transformation, OT）**

interface TransformFunction {

}

// 示例：两个删除操作的转换
function transformDeleteDelete(
  op1: DeleteOperation,
  op2: DeleteOperation
): [DeleteOperation, DeleteOperation] {
  if (op1.strokeId === op2.strokeId) {
    // 删除同一个笔触，第二个操作变为空操作
    return [op1, { ...op2, type: 'noop' }];
  }
  // 删除不同笔触，无需转换
  return [op1, op2];
}
```

#### 类型 3：网络分区冲突
**场景**：网络断开后重新连接，本地状态与服务器不一致

**解决方案：状态合并（State Merging）**
```typescript
function mergeStates(
  localState: CanvasState,
  serverState: CanvasState
): CanvasState {
  // 1. 合并笔触（按ID去重，保留最新版本）
  const mergedStrokes = new Map<string, Stroke>();
  
  // 添加服务器笔触
  serverState.strokes.forEach(stroke => {
    mergedStrokes.set(stroke.id, stroke);
  });
  
  // 合并本地笔触（如果更新则覆盖）
  localState.strokes.forEach(stroke => {
    const existing = mergedStrokes.get(stroke.id);
    if (!existing || stroke.timestamp > existing.timestamp) {
      mergedStrokes.set(stroke.id, stroke);
    }
  });
  
  return {
    ...serverState,
    strokes: Array.from(mergedStrokes.values()),
  };
}
```

#### 重连流程
```typescript
class ReconnectionManager {
  async reconnect(): Promise<void> {
    // 1. 保存本地未同步操作
    const pendingOps = this.getPendingOperations();
    
    // 2. 获取服务器最新状态
    const serverState = await this.fetchLatestState();
    
    // 3. 合并状态
    const mergedState = this.mergeStates(
      this.localState,
      serverState
    );
    
    // 4. 重放未同步操作
    for (const op of pendingOps) {
      const transformedOp = this.transformOperation(op, serverState);
      this.applyOperation(mergedState, transformedOp);
    }
    
    // 5. 同步到服务器
    await this.syncToServer(mergedState);
  }
}
```

function detectConflicts(
  localOps: Operation[],
  serverOps: Operation[]
): Conflict[] {
  const conflicts: Conflict[] = [];
  
  // 检测操作顺序冲突
  const localOrder = getOperationOrder(localOps);
  const serverOrder = getOperationOrder(serverOps);
  
  if (!arraysEqual(localOrder, serverOrder)) {
    conflicts.push({
      type: 'order_conflict',
      localOps,
      serverOps,
    });
  }
  
  // 检测数据冲突
  const conflictingStrokes = findConflictingStrokes(
    localOps,
    serverOps
  );
  
  conflictingStrokes.forEach(stroke => {
    conflicts.push({
      type: 'data_conflict',
      strokeId: stroke.id,
      localVersion: stroke.localVersion,
      serverVersion: stroke.serverVersion,
    });
  });
  
  return conflicts;
}
